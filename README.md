# 🎙️ CARAX - Voice Assistant

A Python-based voice assistant that listens to voice commands and performs useful tasks such as opening websites, searching Google/YouTube/Amazon, and playing YouTube videos.

## ✨ Features

- 🎙️ Voice command recognition
- 🔊 Text-to-speech responses
- 🌐 Open websites using voice commands
- 🔎 Google search
- ▶️ YouTube search
- 🎵 Play YouTube videos
- 🛒 Amazon product search
- 💻 Open GitHub, LinkedIn, ChatGPT and other websites
- 🖥️ Local HTTP server for YouTube playback

## 🛠️ Technologies

- Python
- SpeechRecognition
- SoundDevice
- pyttsx3
- yt-dlp
- YouTube IFrame API
